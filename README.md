# 이 단체, 어떤 활동을 했을까?

공개된 언론 기사와 단체 성명·보도자료에서 단체명이 직접 언급된 집회·성명 활동을 출처와 함께 정리한 아카이브입니다. 어떠한 평가도 하지 않습니다.

- `data.json`: 이슈·출처·기록 데이터 (기록마다 출처 URL과 짧은 근거 발췌)
- `index.html`, `app.js`: 정적 페이지 (빌드 없음)

기록 기준: 이슈별 입장 조건 중 하나라도 해당하는 직접 활동만 횟수로 집계(같은 단체·같은 사건·같은 날은 1회). 연대체 참가단체 명단에 이름이 있는 경우는 "연대체 가입"으로 따로 기록하며 횟수에 넣지 않음. 날짜를 일 단위로 확정하지 못한 기록은 별도 표시.
